# Српски дневник — электронный учебник сербского

Бесплатный учебник сербского языка для русскоязычных: 13 недель от алфавита до уровня A1+/A2−. Коммуникативный подход и обучение на задачах, оба алфавита, экавский вариант.

Уроки сделаны на основе материалов сайта [Go-Serbia](https://lang.go-serbia.net/) и используются исключительно в некоммерческих целях (по договорённости с владельцами). Материалы из других источников не копируются: только ссылки и официальное встраивание.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # Vitest: логика и целостность содержания
npm run build    # проверка типов + сборка в dist/
```

Перед каждым коммитом должны проходить `npm test` и `npm run build`.

## Стек

Vite + React + TypeScript, React Router, MDX (содержание уроков), Zustand (состояние, localStorage), CSS Modules + CSS-переменные (темы), Vitest. Деплой — Vercel (`vercel.json` перенаправляет все адреса на SPA).

## Структура

```
src/
  lib/              чистая логика под тестами: translit, answer, srs (SM-2), xp, storage, progressFile
  store/            Zustand: весь прогресс в одном persist-объекте; hooks.ts — алфавит и род
  content/
    course.ts       оглавление 13 недель (недели без папки показываются как «скоро»)
    registry.ts     автоматически находит недели в content/weeks/NN
    weeks/NN/       week.ts (мета), vocab.ts, exercises.ts, s1…s6.mdx, checkin.mdx
    cheatsheets/    шпаргалки (MDX с export const meta)
    checkpoints/    контрольные точки N.mdx (появляются на неделях 4, 8, 13)
    pages/          ресурсы
  components/       sr/ (сербский текст), content/ (аудио, видео, блоки), exercises/ (7 типов), layout/
  pages/            страницы по маршрутам
public/audio/go-serbia/   аудио курса Go-Serbia (кешируется при первом прослушивании)
```

## Как добавить неделю

1. Создай папку `src/content/weeks/NN/` (по образцу `01`).
2. `week.ts` — тема, цели «я могу…», грамматика, лексика, культура, задача, список занятий.
3. `vocab.ts` — словарик (поле `lesson` указывает занятие; `falseFriend` — ложный друг).
4. `exercises.ts` — упражнения со стабильными `id` вида `wN.sM.name`.
5. `s1.mdx … s6.mdx`, `checkin.mdx` — тексты занятий.

Код менять не нужно. `npm test` проверит, что все `<Exercise id>` и аудиофайлы на месте, а предложения в «собери предложение» собираются из выданных слов.

## Соглашения в содержании

- **Сербский текст пишется кириллицей**, латиница получается автоматически (кириллица → латиница однозначна; обратно — нет, поэтому `latToCyr` используется только для сравнения ответов).
- В MDX `обратные кавычки` = сербский текст: `` `Ја сам` `` переключается вместе с алфавитом. Для блоков — `<Sr block>…</Sr>`.
- В строках данных (week.ts, инструкции упражнений) сербские фрагменты тоже отмечаются обратными кавычками.
- Формы по роду ученика: в MDX `<G f="уморна" m="уморан" />` (сербский) и `<Ru f="сама" m="сам" />` (русский); в данных — `{ f: '…', m: '…' }`.
- Шаблоны в `<ChatBlock template={…}>`: `[[женская|мужская]]`, `{{сербский текст}}`, `((если кириллица|если латиница))`.
- Компоненты MDX: `Audio`, `Video` (youtube-nocookie, загрузка по клику), `Exercise`, `Vocab`, `ChatBlock` (report / ai / people), `MiniLesson`, `Trap`, `Culture`, `Tip`, `Dialogue`, `AlphabetTable`, `NewLetters`.
- Каждую внешнюю ссылку и ID видео проверяем до вставки.

## Данные и приватность

- Прогресс хранится только в браузере (localStorage, ключ `srpski-textbook`). Все обращения обёрнуты в try/catch: без хранилища приложение работает, данные живут до закрытия вкладки.
- Перенос между устройствами — экспорт/импорт JSON в настройках. У записей есть `updatedAt`, а в `lib/progressFile.ts` есть `mergeRecords` («новее побеждает») — задел для облачной синхронизации.
- Счётчик посетителей (этап 2): Vercel Function + Upstash Redis. Браузер ставит в localStorage флажок «уже посчитан» (не идентификатор) и один раз отправляет POST. Без cookies, IP и персональных данных, на localhost не считает. **Ограничение:** считается уникальный браузер/устройство, а не человек — тот же человек с телефона и ПК или после очистки данных сайта будет посчитан повторно.
