# Српски дневник — электронный учебник сербского

Бесплатный учебник сербского языка для русскоязычных: 13 недель от алфавита до уровня A1+/A2−. Коммуникативный подход и обучение на задачах, оба алфавита, экавский вариант.

Уроки сделаны на основе материалов сайта [Go-Serbia](https://lang.go-serbia.net/), дополненных материалами из других открытых источников. Всё используется исключительно в некоммерческих целях (по договорённости с владельцами); у каждого задания указан источник со ссылкой.

**Методические правила курса** (источники, подпись «(c) …», проверка аудио, практика с ИИ на четыре навыка) — в [`CLAUDE.md`](CLAUDE.md). Аудио и видео, ждущие проверки, — в [`docs/media-review.md`](docs/media-review.md).

## Лицензия

Лицензия MIT (файл `LICENSE`) распространяется **только на код**. Тексты, упражнения и аудио курса Go-Serbia используются по договорённости с владельцами только в некоммерческих целях: на них MIT не распространяется, повторное использование — с разрешения [Go-Serbia](https://lang.go-serbia.net/).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # Vitest: логика и целостность содержания
npm run build    # проверка типов + сборка в dist/
```

Перед каждым коммитом должны проходить `npm test` и `npm run build`.

## Стек

Vite + React + TypeScript, React Router, MDX (содержание уроков), Zustand (состояние, localStorage), CSS Modules + CSS-переменные (темы), Vitest. Деплой — Vercel (`vercel.json` перенаправляет все адреса на SPA).

### Аудио

Каждое аудио до использования в задании проверяет автор курса (`docs/media-review.md`): диктор должен произносить ровно то, что написано в задании.

Из сети, где ведётся проект, большие файлы не загружаются на GitHub одним запросом, поэтому mp3 хранятся в `audio-src/` кусками до 400 КБ. Перед `dev`, `build` и `test` скрипт `scripts/join-audio.mjs` склеивает их в `public/audio/go-serbia/` и проверяет контрольные суммы (на Vercel тоже). Чтобы добавить аудио: положи mp3 в `public/audio/<папка>/` и запусти `npm run split-audio -- <папка>`.

## Как добавить неделю

1. Создай папку `src/content/weeks/NN/` (по образцу `01`).
2. `week.ts` — тема, цели «я могу…», грамматика, лексика, культура, задача, список занятий.
3. `vocab.ts` — словарик (поле `lesson` указывает занятие; `falseFriend` — ложный друг).
4. `exercises.ts` — упражнения со стабильными `id` вида `wN.sM.name`; у взятых из источника — `source`.
5. `s1.mdx … s6.mdx`, `checkin.mdx` — тексты занятий.

Код менять не нужно. `npm test` проверит, что все `<Exercise id>` и аудиофайлы на месте, а предложения в «собери предложение» собираются из выданных слов.

## Соглашения в содержании

- **Сербский текст пишется кириллицей**, латиница получается автоматически (кириллица → латиница однозначна; обратно — нет, поэтому `latToCyr` используется только для сравнения ответов).
- В MDX `обратные кавычки` = сербский текст: `` `Ја сам` `` переключается вместе с алфавитом. Для блоков — `<Sr block>…</Sr>`.
- В строках данных (week.ts, инструкции упражнений) сербские фрагменты тоже отмечаются обратными кавычками.
- Формы по роду ученика: в MDX `<G f="уморна" m="уморан" />` (сербский) и `<Ru f="сама" m="сам" />` (русский); в данных — `{ f: '…', m: '…' }`.
- Шаблоны в `<ChatBlock template={…}>`: `[[женская|мужская]]`, `{{сербский текст}}`, `((если кириллица|если латиница))`.
- Компоненты MDX: `Audio` (`source` — подпись источника), `Video` (youtube-nocookie, загрузка по клику, `author` — автор/канал), `Exercise`, `Vocab`, `ChatBlock` (report / ai / people; у `ai` обязателен `skill`: reading / writing / listening / speaking), `Source` (подпись «(c) …» внизу блока), `MiniLesson`, `Trap`, `Culture`, `Tip`, `Dialogue`, `AlphabetTable`, `NewLetters`.
- Источник задания — только мелкой подписью внизу (`source` в упражнении, `<Source id>` в MDX), не в заголовке. Задания нумеруются автоматически в рамках занятия.
- Каждую внешнюю ссылку и ID видео проверяем до вставки.

## Публикация и офлайн

- **Vercel** собирает сайт при каждом push в `main` (`npm run build`, папка `dist`). `vercel.json`: SPA-перенаправления и заголовки кеша (`sw.js` без кеша, `assets/` навсегда).
- **PWA** (`vite-plugin-pwa`, режим injectManifest, `src/sw.ts`). При установке кешируются оболочка, тексты уроков и иконки (~0,5 МБ). Аудио заранее не кешируется: при первом прослушивании файл скачивается целиком и дальше играет офлайн (плеер запрашивает куски через Range — они отдаются из кеша).
- Иконки генерируются из `public/favicon.svg`: `npx pwa-assets-generator` (настройки в `pwa-assets.config.ts`).
- Проверить PWA локально: `npm run build && npm run preview`.

## Данные и приватность

- Прогресс хранится только в браузере (localStorage, ключ `srpski-textbook`). Все обращения обёрнуты в try/catch: без хранилища приложение работает, данные живут до закрытия вкладки.
- Перенос между устройствами — экспорт/импорт JSON в настройках. У записей есть `updatedAt`, а в `lib/progressFile.ts` есть `mergeRecords` («новее побеждает») — задел для облачной синхронизации.
- Счётчик посетителей (этап 2): Vercel Function + Upstash Redis. Браузер ставит в localStorage флажок «уже посчитан» (не идентификатор) и один раз отправляет POST. Без cookies, IP и персональных данных, на localhost не считает. **Ограничение:** считается уникальный браузер/устройство, а не человек — тот же человек с телефона и ПК или после очистки данных сайта будет посчитан повторно.
