# Глагол `бити` — «быть»

Главный глагол сербского: без него не построить даже «я студент». Подробно разбираем на неделе 2.

| | Краткая форма | Полная (ударная) | Отрицание |
|---|---|---|---|
| ја | `сам` | `јесам` | `нисам` |
| ти | `си` | `јеси` | `ниси` |
| он, она, оно | `је` | `јесте` | `није` |
| ми | `смо` | `јесмо` | `нисмо` |
| ви | `сте` | `јесте` | `нисте` |
| они, оне, она | `су` | `јесу` | `нису` |

- **Краткие формы** — клитики: никогда не стоят первыми. `Ја сам Ана.` `Студент сам.`
- **Полные формы** — для ответа и вопроса: `Јеси ли ти Марко?` — `Јесам.` (Ты Марко? — Да.)
- **Отрицание** пишется слитно и может стоять первым: `Нисам` <G f="уморна." m="уморан." />
- **Вопрос:** `Да ли си` <G f="уморна?" m="уморан?" /> или `Јеси ли` <G f="уморна?" m="уморан?" />
