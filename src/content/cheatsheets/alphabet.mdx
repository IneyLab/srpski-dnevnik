# Алфавит

<AlphabetTable />

- **Один звук — одна буква.** `љ = lj`, `њ = nj`, `џ = dž` — одна буква, хотя на латинице два знака.
- **Пары:** `ч` твёрдое — `ћ` мягкое; `џ` твёрдое — `ђ` мягкое.
- **Нет в сербском:** ё, й, щ, ъ, ы, ь, э, ю, я. Вместо «я, ю, ё» — `ја, ју, јо`, вместо «э» — `е`.
- **Ловушки латиницы:** *c* = ц, *h* = х, *j* = й, *p* = п, *r* = р, *n* = н, *u* = у.
- **Без сербской раскладки** *đ* пишут как *dj*.
- **Произношение:** нет «аканья» (`вода` = [вода]), нет оглушения на конце (`град` = [град]), ударение никогда не на последнем слоге.
