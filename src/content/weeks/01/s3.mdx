**Задача недели:** ты <Ru f="пришла" m="пришёл" /> в таверну, где собирается Гильдия путешественников по Сербии. Чтобы тебя записали в отряд, нужно заполнить **лист персонажа** и представиться хозяину таверны — по-сербски.

## 1. Заполни лист персонажа (10 минут)

Возьми тетрадь и напиши по одной фразе на каждую строку. Можно о себе настоящем, а можно о своём персонаже — главное, чтобы фразы были твоими.

| Поле | Опора | Пример |
|---|---|---|
| Имя | `Зовем се…` / `Ја сам…` | `Зовем се` <G f="Ана." m="Марко." /> |
| Откуда | `Ја сам из…` | `Ја сам из Русије.` / `из Украјине` / `из Белорусије` / `из Казахстана` |
| Кто ты | `Ја сам…` | <G f="Ја сам студенткиња." m="Ја сам студент." /> |
| Что любишь | `Волим…` | `Волим игре.` `Волим друштвене игре.` `Волим путовања.` |
| Хобби | `Мој хоби је…` | `Мој хоби је LARP.` |
| Финал | `Драго ми је!` | |

<Tip title="Готовые блоки, а не грамматика">
  `из Русије`, `Волим игре`, `Волим путовања` — пока просто готовые фразы, запоминай их целиком. Почему после `из` слово меняется (`Русија → из Русије`), разберём позже: это родительный падеж. Если твоей страны или хобби нет в таблице, спроси у ИИ в ролевой игре: «Как сказать…?»
</Tip>

Ещё несколько полезных «профессий» для строки «Кто ты» (женская / мужская форма): `студенткиња / студент`, `учитељица / учитељ` (учительница / учитель), `програмерка / програмер`, `дизајнерка / дизајнер`, `инжењерка / инжењер`.

Пример целиком:

<Sr block>
  <G f="Здраво! Зовем се Ана. Ја сам из Русије. Ја сам студенткиња. Волим игре и путовања. Мој хоби је LARP. Драго ми је!" m="Здраво! Зовем се Марко. Ја сам из Русије. Ја сам студент. Волим игре и путовања. Мој хоби је LARP. Драго ми је!" />
</Sr>

**Проверь перед игрой:** в каждой фразе с «я есть…» стоит `сам`? `се` и `сам` не стоят первыми?

## 2. Ролевая игра с ИИ (15–20 минут)

  Открой **новый чат** в любом ИИ-ассистенте, вставь промпт и играй. Отвечай фразами из своего листа персонажа. Если хочешь потренировать говорение, отвечай голосом, если чат это умеет.

Во время игры:

- не подсматривай в перевод сразу — сначала попробуй понять вопрос;
- если не знаешь слова, напиши его по-русски в скобках: ИИ подскажет;
- новые полезные фразы выписывай в банк фраз.
